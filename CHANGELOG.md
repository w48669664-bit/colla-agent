## [0.1.1] - 2026-07-28

### Fixed

## [0.1.0] - 2026-07-28

### Added

- Local Colla Agent Dashboard for observable Codex–Antigravity collaboration.
- Globally installable `$relay-room-collaboration` Codex Skill.
- Host-session protocol with the current Codex session as the sole writer.
- Read-only Antigravity planning and review consultations.
- Bounded 1 / 3 / 5 / 8 / 12 review policy and repeated-finding guard.
- Progressive public activity events, quiet-review pulses and per-round traces.
- Provider allowance and per-run usage summaries.
- Project-local durable run snapshots and explicit completion records.
- Path-safe previews for web, media, PDF, text, code and generic files.
- Neon Snake and Release Readiness Simulator reference workloads.
- Desktop/mobile layouts, reduced motion, keyboard focus and accessible status labels.
- Unit, integration, build and deterministic smoke-test coverage.
