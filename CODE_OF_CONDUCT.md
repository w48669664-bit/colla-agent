# Code of Conduct

Colla Agent contributors are expected to keep collaboration respectful,
evidence-based and welcoming.

## Expected behavior

- Be considerate and specific in reviews.
- Critique ideas and implementations, not people.
- Provide reproducible evidence for technical claims.
- Respect privacy, credentials and unpublished project information.
- Welcome contributors regardless of background, identity or experience.
- Accept maintainer decisions made to protect safety, scope or project health.

## Unacceptable behavior

- Harassment, discrimination, threats or personal attacks.
- Publishing another person's private information.
- Deliberately introducing malicious code, credential collection or unsafe
  agent behavior.
- Repeatedly disrupting discussions after a maintainer has set a boundary.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub
profile or a private Security Advisory when the concern also involves
security. Maintainers may edit or remove content, close discussions, reject
contributions or restrict participation when necessary.
