# Product

## Register

product

## Users

Developers and technical leads running local, multi-agent delivery workflows. They need to see what each agent was asked, what it answered, which files changed, how much provider allowance remains, and why an iterative run continued or stopped.

## Product Purpose

Colla Agent is a reusable local collaboration workspace for Codex and Antigravity, powered by the Relay Room runtime. A globally installed Codex Skill starts the dashboard for any active project while the current Codex session remains the implementation owner. Antigravity plans and reviews read-only, local verification supplies evidence, registered deliverables receive native previews, and explicit stop conditions prevent silent or wasteful model calls. Snake remains a compact reference workload; the Release Readiness Simulator demonstrates the broader product boundary.

## Brand Personality

Precise, candid, collaborative. The interface should feel like an engineering instrument with editorial restraint: trustworthy enough for operational decisions, approachable enough to follow in real time, and never theatrical about autonomy.

## Anti-references

- Oversized marketing heroes that displace the active run.
- Fixed “agent stage” cards that pretend every project follows the same sequence.
- Fake terminal chrome, decorative dashboards, or fabricated quota precision.
- Infinite-loop language that implies agents can spend allowance without a stopping policy.
- A game-specific identity that prevents the console from scaling to larger software projects.
- A recursive Codex process hidden inside an already-running Codex session.
- Claims that private chain-of-thought is available to the dashboard.

## Design Principles

- Show the real exchange: prompts, responses, commands, edits, tests, and handoffs stay inspectable.
- Separate provider allowance from per-run consumption so users understand what a click costs.
- Make autonomy bounded and legible: complexity chooses a plan, while pass, stagnation, caps, and manual stop end it.
- Present Codex and Antigravity as accountable colleagues with distinct responsibilities, not interchangeable chat bubbles.
- Let the active project shape the artifact area without making the control plane project-specific.
- Preserve every run inside the active project so decisions and evidence remain replayable.
- Preview the output in its native form: interactive web, playable game, media, document, text, or file.

## Accessibility & Inclusion

Target WCAG 2.2 AA for contrast and interaction. Preserve visible keyboard focus, semantic controls and landmarks, readable monospace output, mobile layouts without page overflow, non-color status labels, and reduced-motion behavior.
